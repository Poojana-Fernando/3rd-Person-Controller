# Third Person Controller

Unity third-person controller project built on Invector LITE with a Resident Evil-style gun and aim system.

## Requirements

- Unity 6
- Open `Assets/Scenes/MainScene.unity`

## What is included in Git

This repository follows the standard Unity `.gitignore` setup. It includes:

- `Assets/`
- `Packages/`
- `ProjectSettings/`

It does **not** include generated Unity folders such as:

- `Library/`
- `Temp/`
- `Logs/`
- `UserSettings/`

After cloning, open the project in Unity and let it regenerate `Library/` locally.

## Controls

- `1` — equip / holster gun
- Right mouse button — aim
- Left mouse button — fire while aiming
- `WASD` — move
- Mouse — camera / aim look
- `Tab` — strafe mode
- `Shift` — sprint
